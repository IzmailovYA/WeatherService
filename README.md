# Сервис получения метеорологических данных

Консольное приложение на Java для получения и анализа данных о погоде 

## Функционал приложения
Выполняет HTTP-запрос к API Яндекс.Погоды с передачей координат города и авторизационного токена.
Выводит JSON-ответ от сервера в консоль.
Извлекает и отображает текущую температуру.
Рассчитывает среднюю арифметическую температуру по дневным прогнозам на заданное количество суток.
